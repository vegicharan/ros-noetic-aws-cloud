# ROS Noetic on AWS EC2 (Ubuntu 20.04)

This project sets up **ROS Noetic** (Robot Operating System) on an **AWS EC2 Ubuntu instance**, allowing you to run and test ROS applications on the cloud.

## 🚀 Project Overview

- Install **ROS Noetic Full Desktop** on a cloud server.
- Use a shell script (`install_ros.sh`) to automate the setup.
- Host the setup on GitHub for easy version control and portability.

## 🧰 Requirements

- AWS EC2 instance (Ubuntu 20.04 preferred)
- Git installed
- SSH access to your EC2 instance
- A GitHub account and personal access token
